# Navigation and use-case review

The original DeepGrid site was compared with the rebuild. The local rebuild now provides:

- Compact, clearly named navigation; a labeled phone menu; breadcrumbs and previous/next section links.
- Products with visible search, category counts, compact summaries, restored portfolio context, and direct source-slide links.
- Return paths that preserve the selected product, category, search text and scroll position.
- A question field at the start of the briefing view, with retained briefing context after visiting source slides.
- The original 104 slide images served locally, plus chapter selection, direct slide entry, commentary and model references recovered from the original source.
- An investment reader divided into overview, executive summary, business, technology, use cases, strategy and financial risk.
- Six structured use-case cards. Each opens a dedicated buyer/deliverable/acceptance-gate/risk view, a four-step workflow, related product navigation and expandable source context. A separate three-stage execution plan replaces the continuous narrative.

Validation: desktop and phone browser checks; 320px and 768px overflow checks; browser Back, filtered product-to-slide return, scroll restoration, deep links and reload; all six use cases and return links at 1440px, 390px and 320px. Mobile validation uses browser emulation, not a physical phone. Regulatory and financial content retains its original management-source context.

The public GitHub Pages site has not been changed. The updated preview runs at http://localhost:3000/.
