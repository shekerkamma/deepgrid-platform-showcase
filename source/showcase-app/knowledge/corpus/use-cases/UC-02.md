# DeepGrid Semi — use-cases/UC-02

All figures are management projections from DeepGrid's fundraising materials.

## UC-02 Nuisance-alert suppression

Nuisance-alert suppression. Standard: AIS-162 §6.8 false-reaction test. Dates: Gates every AEBS approval from 1 Jan 2027. Challenge: Four rivals already claim India tuning. India-native is no longer a differentiator. What no competitor has published is a measured nuisance rate — and AIS-162 tests for exactly that. What Deepgrid supplies: The denominator rather than the headline: a scenario-stratified false-positive rate per 1,000 km against a named baseline, on the same silicon class, the same functions and the same test set. Steps: Define the India nuisance set — overtaking two-wheelers, cut-in three-wheelers, cattle, roadside encroachment, unlit stationary trucks, wrong-way traffic, kerbside vending; Log every trigger and every non-trigger with scenario tags across three paid pilots, with telemetry rights secured in the contract; Score false positives per 1,000 km and true-positive recall, stratified by scenario, lighting and monsoon; Publish at equal scope; withhold any comparison that silently changes what is being compared. Buyer: Head of Validation · Tier-1 evaluation engineer · fleet safety manager Gate: One published equal-scope benchmark with scenario-stratified denominators and an independent agency’s protocol. Risk: A nuisance rate without a denominator is marketing. If scenario mix, kilometres and baseline are not fixed in advance, the result will be discounted to zero in a Tier-1 review.
